# Canonical MCP Notes

- source canonica: `registry/mcp/claude-project-mcp-seed/definition.json`
- server eseguibile: `registry/mcp/claude-project-mcp-seed/server.py`
- Codex MCP è configurato in: `%USERPROFILE%\.codex\config.toml` (`[mcp_servers.*]`)
- Claude project MCP viene scritto in: `<repo>\.mcp.json`
- Gemini MCP viene configurato nel JSON delle impostazioni (`mcpServers`) quando l’operatore decide di collegarlo
