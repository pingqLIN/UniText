# UniText — Shortlist delle skill essenziali

> Stato: Active
> Uso: definire il set principale della review esterna, mantenendo solo il selettore `8 + 4` invece dell’intero pool di candidate skill.

## Regola di selezione

Questa shortlist è costruita sul tema delle “skill essenziali”. I criteri sono:

- utili in più progetti
- rappresentano il valore reale del shared registry
- il loro scopo è comprensibile anche all’esterno
- preferenza per skill complesse o di ingresso, con script, reference e sample

## Core 8

| Skill | Perché resta |
|---|---|
| `pdf` | molto generale, molto complessa, con diversi script e reference docs |
| `docx` | molto generale, molto complessa, con tooling OOXML e asset di schema |
| `xlsx` | molto generale, rappresenta workflow strutturati e spreadsheet |
| `pptx` | completa il tipo di artifact office, con script ed esempi |
| `mcp-builder` | molto vicina alla posizione di UniText, chiaramente una skill di ingresso / piattaforma |
| `skill-creator` | supporta direttamente l’espansione dell’ecosistema delle skill, quindi è una skill di ingresso |
| `webapp-testing` | rappresenta workflow QA / browser interattivi e verificabili |
| `doc-coauthoring` | copre structured writing e workflow per specifiche / documenti |

## Controllo skill complesse / di ingresso

Questo set `8 + 4` non richiede l’aggiunta di altri tipi, perché include già più skill complesse o di ingresso:

- `pdf`
- `docx`
- `pptx`
- `mcp-builder`
- `skill-creator`
- `webapp-testing`

Ognuna di queste skill ha almeno uno tra:

- script interni
- documenti di reference
- asset di template o esempio

## Fuori ambito per questa ondata di review

Al momento non rientrano nella shortlist:

- la famiglia di skill specifiche di Hugging Face
- skill verticali di arte, branding o GIF
- altre skill molto specializzate ma non essenziali

Questo non significa che non abbiano valore; significa solo che, per ora, non fanno parte del tema “skill essenziali”.
