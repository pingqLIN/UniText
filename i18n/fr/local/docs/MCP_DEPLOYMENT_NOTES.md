# Notes canoniques MCP

- source canonique : `registry/mcp/claude-project-mcp-seed/definition.json`
- serveur exécutable : `registry/mcp/claude-project-mcp-seed/server.py`
- la configuration MCP de Codex se trouve dans : `%USERPROFILE%\.codex\config.toml` (`[mcp_servers.*]`)
- le MCP projet Claude est écrit dans : `<repo>/.mcp.json`
- le MCP Gemini est configuré dans le JSON de paramètres (`mcpServers`) lorsque l’opérateur choisit de le brancher
