# UniText — Sélection essentielle des skills

> Statut : `Active`
> Utilité : définir la base de revue externe actuelle, en conservant seulement le groupe `8 + 4` de skills sélectionnés, et non l’ensemble complet des candidats.

## Règle de sélection

Cette shortlist suit le thème du « skill essentiel » avec les critères suivants :

- utile à plusieurs projets
- capable de représenter la valeur réelle du shared registry
- facilement compréhensible par un relecteur externe
- priorité aux skills complexes ou de type entrée, avec scripts, références ou exemples

## Core 8

| Skill | Pourquoi il reste |
|---|---|
| `pdf` | Très générique et complexe, avec plusieurs scripts et docs de référence |
| `docx` | Très générique et complexe, avec du tooling OOXML et des assets de schéma |
| `xlsx` | Très générique, représente les données structurées et les workflows tableur |
| `pptx` | Complète la catégorie des artefacts Office, avec scripts et assets d’exemple |
| `mcp-builder` | Très proche du positionnement d’UniText, skill d’entrée / de plateforme clairement défini |
| `skill-creator` | Soutient directement l’expansion de l’écosystème de skills, donc skill d’entrée |
| `webapp-testing` | Représente un workflow QA / navigateur interactif et vérifiable |
| `doc-coauthoring` | Complète le type de workflow de rédaction structurée / spec |

## Expansion 4

| Skill | Pourquoi il reste |
|---|---|
| `frontend-design` | Représente la catégorie des sorties UI / frontend |
| `web-artifacts-builder` | Complète les artefacts plus lourds et la composition d’applications |
| `internal-comms` | Représente les usages internes de collaboration et de reporting |
| `theme-factory` | Représente le styling / theming et complète la couche de sortie des artefacts |

## Vérification des skills complexes / d’entrée

Ce `8 + 4` n’a pas besoin d’ajouter un nouveau type, car il contient déjà plusieurs skills complexes ou de type entrée :

- `pdf`
- `docx`
- `pptx`
- `mcp-builder`
- `skill-creator`
- `webapp-testing`

Ces skills disposent au moins d’un des éléments suivants :

- scripts internes
- docs de référence
- assets de template / d’exemple

## Hors périmètre pour cette vague de revue

Les catégories suivantes ne font pas partie de la base de revue externe actuelle :

- la famille de skills dédiée à Hugging Face
- les skills orientés art / branding / GIF
- les autres skills très spécifiques qui ne sont pas essentiels

Ils ne sont pas sans valeur, ils ne sont simplement pas dans le thème « skill essentiel » pour l’instant.
