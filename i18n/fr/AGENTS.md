# AGENTS.md

## Règle de non-publication

Ce dépôt contient des éléments qui doivent rester privés, sauf autorisation explicite de l’utilisateur.

Les agents qui opèrent dans ce dépôt doivent respecter les règles suivantes :

1. Ne poussez aucun commit vers un dépôt distant sans demande explicite de l’utilisateur.
2. N’envoyez pas le contenu du dépôt vers GitHub, les plateformes sociales, les documents cloud, les sites de collage ou tout autre service réseau sans demande explicite de l’utilisateur.
3. Considérez comme particulièrement sensibles par défaut :
   - les brouillons de messages sociaux
   - les notes de comparaison entre projets
   - les discussions de collaboration inter-projets
   - les notes de revue
   - les documents de planification stratégique
4. Si l’utilisateur demande une publication, un push, un upload ou un post, ne publiez que le contenu qu’il a approuvé.
5. En cas de doute, gardez le contenu en local et demandez avant toute publication.

## Note de périmètre

Cette politique s’applique même lorsque :

- un dépôt distant existe déjà
- le dépôt est privé
- le contenu semble prêt à être publié

Un dépôt privé n’équivaut pas à une autorisation automatique de publication.
