# Canonical MCP Notes
- Canonical source: `registry/mcp/claude-project-mcp-seed/definition.json`
- Runnable server: `registry/mcp/claude-project-mcp-seed/server.py`
- Codex MCP は `%USERPROFILE%\.codex\config.toml` の `[mcp_servers.*]` で設定する
- Claude project MCP は `<repo>/.mcp.json` に書き込まれる
- Gemini MCP は、運用者が接続する場合に settings JSON の `mcpServers` で設定する
