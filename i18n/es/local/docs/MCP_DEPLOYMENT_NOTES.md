# Notas Canónicas de MCP
- Fuente canónica: `registry/mcp/claude-project-mcp-seed/definition.json`
- Servidor ejecutable: `registry/mcp/claude-project-mcp-seed/server.py`
- Codex MCP se configura en: `%USERPROFILE%\.codex\config.toml` (`[mcp_servers.*]`)
- El MCP de proyecto de Claude se escribe en: `<repo>/.mcp.json`
- Gemini MCP se configura en el JSON de settings (`mcpServers`) cuando el operador decide conectarlo
