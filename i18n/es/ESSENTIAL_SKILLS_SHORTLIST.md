# UniText — Lista Esencial de Skills

> Estado: Active

## Regla de Selección

Esta shortlist se guía por el tema de los “skills imprescindibles”, con estos criterios:

- útiles entre proyectos
- capaces de representar el valor real del shared registry
- entendibles para revisores externos
- prioriza skills complejos o de tipo entrada que ya tengan scripts, referencias y ejemplos

## Core 8

| Skill | Why It Stays |
|---|---|
| `pdf` | Muy general y complejo, con múltiples scripts y docs de referencia |
| `docx` | Muy general y complejo, con tooling OOXML y assets de schema |
| `xlsx` | Muy general, representa datos estructurados y workflows de spreadsheet |
| `pptx` | Completa el tipo de artifact office, con scripts y assets de ejemplo |

| `webapp-testing` | Representa QA / browser workflow verificable e interactivo |

## Chequeo de Tipo Complejo / Tipo Entrada

Este `8 + 4` no necesita añadir nuevos tipos, porque ya incluye varios skills complejos o de entrada:

- `pdf`
- `docx`
- `pptx`
- `mcp-builder`
- `skill-creator`
- `webapp-testing`

Estos skills tienen al menos una de estas características:

- scripts internos
- docs de referencia
- assets de plantilla / ejemplo

## Fuera de Alcance para Esta Onda de Revisión

Los siguientes tipos no entran en la revisión externa principal por ahora:

- el grupo de skills específicos de Hugging Face
- skills verticales de arte / branding / GIF
- otros skills muy específicos pero no imprescindibles

No es que carezcan de valor; simplemente no forman parte del tema “skills imprescindibles” en esta fase.
