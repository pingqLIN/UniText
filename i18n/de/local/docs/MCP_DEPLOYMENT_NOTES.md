# Kanonische MCP-Notizen

- kanonische Quelle: `registry/mcp/claude-project-mcp-seed/definition.json`
- ausführbarer Server: `registry/mcp/claude-project-mcp-seed/server.py`
- Codex MCP ist konfiguriert in: `%USERPROFILE%\.codex\config.toml` (`[mcp_servers.*]`)
- das Claude-Projekt-MCP wird geschrieben nach: `<repo>/.mcp.json`
- Gemini MCP wird in der Settings-JSON (`mcpServers`) konfiguriert, wenn der Operator es anbinden möchte
