# AGENTS.md

## No-Publish-Regel

Dieses Repository enthält Materialien, die ohne ausdrückliche Erlaubnis des Nutzers privat bleiben können.

Agents, die in diesem Repository arbeiten, MÜSSEN die folgenden Regeln befolgen:

1. Keine Commits an irgendein Remote pushen, außer der Nutzer verlangt diesen Push ausdrücklich.
2. Repository-Inhalte nicht auf GitHub, Social-Plattformen, Cloud-Dokumente, Paste-Dienste oder andere Netzwerkdienste hochladen, außer der Nutzer verlangt diesen Upload ausdrücklich.
3. Die folgenden Inhalte sind standardmäßig besonders sensibel:
   - Entwürfe für Social Posts
   - Projektvergleichsnotizen
   - projektübergreifende Kollaborationsdiskussionen
   - Review-Notizen
   - strategische Planungsdokumente
4. Wenn der Nutzer Publishing, Push, Upload oder Posten anfordert, dann darf nur der konkret freigegebene Inhalt veröffentlicht werden.
5. Im Zweifel Inhalte lokal behalten und vor dem Veröffentlichen nachfragen.

## Geltungsbereich

Diese Richtlinie gilt auch dann, wenn:

- bereits ein Remote existiert
- das Repository privat ist
- der Inhalt publikationsreif wirkt

Private Repositories bedeuten nicht automatisch eine Freigabe zur Veröffentlichung.
