# UniText — Essential Skills Shortlist

> Status: Aktiv
> Zweck: Definiert die aktuelle externe Review-Topliste und behält nur die `8 + 4` ausgewählten Skills statt des gesamten Kandidatenpools.

## Auswahlregel

Diese Shortlist folgt dem Thema „must-have skills“; die Filterkriterien sind:

- projektübergreifend nützlich
- repräsentativ für den tatsächlichen Wert des Shared Registry
- für externe Reviewer verständlich
- bevorzugt komplexe oder entry-type Skills mit Scripts, References und Examples

## Core 8

| Skill | Warum er bleibt |
|---|---|
| `pdf` | sehr universell, hohe Komplexität, mit mehreren Scripts und Reference-Dokumenten |
| `docx` | sehr universell, hohe Komplexität, mit OOXML-Tooling und Schema-Assets |
| `xlsx` | sehr universell, steht für strukturierte Daten und Spreadsheet-Workflows |
| `pptx` | ergänzt den Office-Artefakt-Typ, mit Scripts und Beispiel-Assets |
| `mcp-builder` | am nächsten an der UniText-Position, klarer Entry-Type / Plattform-Skill |
| `skill-creator` | unterstützt direkt das Skill-Ökosystem, ebenfalls ein Entry-Type |
| `webapp-testing` | steht für verifizierbare, interaktive QA- / Browser-Workflows |
| `doc-coauthoring` | ergänzt strukturierte Schreib- und Spec-Workflows |

## Expansion 4

| Skill | Warum er bleibt |
|---|---|
| `frontend-design` | behält den UI- / Frontend-Output-Typ als Referenz |
| `web-artifacts-builder` | ergänzt den schwereren Artifact- / App-Kompositions-Typ |
| `internal-comms` | erhält einen praktischen Skill für interne Zusammenarbeit und Statusberichte |
| `theme-factory` | behält Styling- / Theming-Typen als Ergänzung für die Artefakt-Ausgabe |

## Complex / Entry-Type Check

Diese `8 + 4`-Auswahl braucht keine weiteren Typen, weil bereits mehrere komplexe oder entry-type Skills enthalten sind:

- `pdf`
- `docx`
- `pptx`
- `mcp-builder`
- `skill-creator`
- `webapp-testing`

Diese Skills besitzen jeweils mindestens eines der folgenden Merkmale:

- interne Scripts
- Reference Docs
- Template- oder Example-Assets

## Nicht im Scope dieser Review-Runde

Die folgenden Typen gehören derzeit nicht zur externen Review-Topliste:

- Hugging-Face-spezifische Skill-Gruppen
- Kunst- / Brand- / GIF-orientierte vertikale Skills
- weitere hochspezialisierte, aber nicht essenzielle Skills

Sie sind nicht wertlos, gehören aber vorerst nicht zum Thema „must-have skill“.
