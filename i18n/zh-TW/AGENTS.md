# AGENTS.md

## 不可發布規則

除非使用者明確允許，這個 repository 內的內容應預設維持私有。

在此 repository 中運作的 agents 必須遵守以下規則：

1. 未經使用者明確要求，不得將 commits push 到任何 remote。
2. 未經使用者明確要求，不得將 repository 內容上傳到 GitHub、社群平台、雲端文件、paste site 或任何其他網路服務。
3. 以下內容預設視為特別敏感：
   - 社群貼文草稿
   - 專案比較筆記
   - 跨專案合作討論
   - 審查筆記
   - 策略規劃文件
4. 如果使用者要求發布、push、upload 或 posting，只能發布使用者明確核准的那一部分內容。
5. 若有疑慮，應先保留在本機，並在發布前詢問。

## 適用範圍說明

即使符合下列情況，本規則仍然適用：

- 已經存在 remote
- repository 是 private
- 內容看起來已可發布

private repository 不等於自動獲得發布授權。
