# UniText — Essential Skills Shortlist

> 状态：Active
> 用途：定义目前外部审查主集，只保留 `8 + 4` 的精选 skills，而不是全量候选池。

## Selection Rule

这份 shortlist 以「必备 skill」为主题，筛选标准如下：

- 跨专案通用
- 能代表 shared registry 的实际价值
- 外部审查看得懂用途
- 优先保留具备 scripts、references、examples 的复杂或入口型 skill

## Core 8

| Skill | Why It Stays |
|---|---|
| `pdf` | 高通用、高复杂度，含多个 scripts 与 reference docs |
| `docx` | 高通用、高复杂度，含 OOXML tooling 与 schema assets |
| `xlsx` | 高通用，代表结构化资料与 spreadsheet workflow |
| `pptx` | 补齐 office artifact 类型，含 scripts 与范例资产 |
| `mcp-builder` | 与 UniText 定位最接近，属于明确的入口型／平台型 skill |
| `skill-creator` | 直接支援 skill 生态扩张，属于入口型 skill |
| `webapp-testing` | 代表可验证、可互动的 QA / browser workflow |
| `doc-coauthoring` | 补齐 structured writing / spec workflow 类型 |

## Expansion 4

| Skill | Why It Stays |
|---|---|
| `frontend-design` | 保留 UI / frontend output 类型代表 |
| `web-artifacts-builder` | 补齐较重型的 artifact / app composition 类型 |
| `internal-comms` | 保留面向内部协作与 status reporting 的实用 skill |
| `theme-factory` | 保留 styling / theming 类型，适合作为 artifact 输出层补充 |

## Complex / Entry-Type Check

这份 `8 + 4` 不需要额外再新增新的类型，因为已经包含多个复杂或入口型 skill：

- `pdf`
- `docx`
- `pptx`
- `mcp-builder`
- `skill-creator`
- `webapp-testing`

这些 skill 都具备至少一项：

- 内部 scripts
- reference docs
- template / example assets

## Out Of Scope For This Review Wave

以下类型目前不列入外部审查主集：

- Hugging Face 专用技能群
- 艺术 / 品牌 / GIF 类垂直技能
- 其他高专用性但非必备的技能

它们不是无价值，而是暂时不属于「必备 skill」主题。
