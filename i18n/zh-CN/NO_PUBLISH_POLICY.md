# UniText — 不可发布政策

> 状态：Active
> 用途：定义哪些内容在未经明确许可前，不得推送、上传或张贴到任何网路服务。

## 1. 核心规则

除非使用者明确授权，否则下列内容不得对外推送、上传、张贴或同步到任何网路服务：

- GitHub push
- 社群平台贴文
- 云端文件
- paste service
- 任何第三方 API 或 hosting service

## 2. 预设敏感内容

以下内容预设视为不可发布：

- 社群文草稿
- 与其他专案的比较或合作讨论
- review notes
- strategy / roadmap / planning 文件
- 尚未正式对外宣告的设计方向

## 3. 授权标准

可发布的前提必须是：

- 使用者明确表示可以发布
- 若只授权部分内容，只能发布被授权的那部分
- `private repo` 不等于自动可发布

## 4. Agent 规则

所有在此 repo 中运作的 agent 应遵守：

1. 未经明确许可，不得 `git push`
2. 未经明确许可，不得将内容贴到社群或任何外部服务
3. 若使用者只允许建立 remote 或建立 private repo，不可自行推定等于允许上传其他敏感内容
4. 若内容涉及其他专案关系、策略讨论或社群文，应采更保守的标准

## 5. 目前明确敏感主题

截至目前，以下类型内容应特别保守处理：

- social post drafts
- `SKILL0_COLLABORATION_VISION.md`
- 其他与 `skill-0` 或外部审查相关的策略讨论

## 6. 操作解读

若未来需要发布，建议分成三步：

1. 先确认允许发布的范围
2. 再确认允许发布的目的地
3. 最后才执行 push / upload / posting
