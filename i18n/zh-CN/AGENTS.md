# AGENTS.md

## 不可发布规则

除非使用者明确允许，这个 repository 内的内容应预设维持私有。

在此 repository 中运作的 agents 必须遵守以下规则：

1. 未经使用者明确要求，不得将 commits push 到任何 remote。
2. 未经使用者明确要求，不得将 repository 内容上传到 GitHub、社群平台、云端文件、paste site 或任何其他网路服务。
3. 以下内容预设视为特别敏感：
   - 社群贴文草稿
   - 专案比较笔记
   - 跨专案合作讨论
   - 审查笔记
   - 策略规划文件
4. 如果使用者要求发布、push、upload 或 posting，只能发布使用者明确核准的那一部分内容。
5. 若有疑虑，应先保留在本机，并在发布前询问。

## 适用范围说明

即使符合下列情况，本规则仍然适用：

- 已经存在 remote
- repository 是 private
- 内容看起来已可发布

private repository 不等于自动获得发布授权。
