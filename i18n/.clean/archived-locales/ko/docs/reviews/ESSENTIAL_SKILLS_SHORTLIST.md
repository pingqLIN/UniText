# UniText — Essential Skills Shortlist

> 상태: Active
> 용도: 현재 외부 리뷰 주력 집합을 정의하며, 전체 후보군이 아니라 `8 + 4`의 핵심 skills만 남깁니다.

## Selection Rule

이 shortlist는 "essential skill"을 주제로 다음 기준으로 선별합니다.

- 여러 프로젝트에 공통으로 유용함
- shared registry의 실제 가치를 보여줌
- 외부 리뷰어가 용도를 이해하기 쉬움
- scripts, references, examples를 갖춘 복잡하거나 entry-type skill을 우선 유지

## Core 8

| Skill | Why It Stays |
|---|---|
| `pdf` | 범용성이 높고 복잡도가 높으며, 여러 scripts와 reference docs를 포함 |
| `docx` | 범용성이 높고 복잡도가 높으며, OOXML tooling과 schema assets를 포함 |
| `xlsx` | 범용성이 높고 구조화된 데이터와 spreadsheet workflow를 대표 |
| `pptx` | office artifact 유형을 보완하며 scripts와 예시 자산을 포함 |
| `mcp-builder` | UniText의 정체성과 가장 가까운 명확한 entry-type / platform-type skill |
| `skill-creator` | skill 생태계 확장을 직접 지원하는 entry-type skill |
| `webapp-testing` | 검증 가능하고 상호작용 가능한 QA / browser workflow를 대표 |
| `doc-coauthoring` | structured writing / spec workflow 유형을 보완 |

## Expansion 4

| Skill | Why It Stays |
|---|---|
| `frontend-design` | UI / frontend output 유형의 대표를 유지 |
| `web-artifacts-builder` | 더 무거운 artifact / app composition 유형을 보완 |
| `internal-comms` | 내부 협업과 status reporting에 유용한 skill을 유지 |
| `theme-factory` | styling / theming 유형을 유지하며 artifact 출력층 보완에 적합 |

## Complex / Entry-Type Check

이 `8 + 4` 집합은 이미 복잡하거나 entry-type인 skill을 여러 개 포함하므로, 추가로 새로운 유형을 더할 필요가 없습니다.

- `pdf`
- `docx`
- `pptx`
- `mcp-builder`
- `skill-creator`
- `webapp-testing`

이들 skill은 최소한 다음 중 하나 이상을 갖고 있습니다.

- internal scripts
- reference docs
- template / example assets

## Out Of Scope For This Review Wave

다음 유형은 현재 외부 리뷰 주력 집합에 포함하지 않습니다.

- Hugging Face 전용 skill군
- 예술 / 브랜드 / GIF 유형의 세로형 skill
- 그 외 고유성이 높지만 essential하지 않은 skill

가치가 없어서가 아니라, 지금의 "essential skill" 주제와는 다르기 때문입니다.
