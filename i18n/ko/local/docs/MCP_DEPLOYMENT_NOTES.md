# Canonical MCP Notes
- Canonical source: `registry/mcp/claude-project-mcp-seed/definition.json`
- Runnable server: `registry/mcp/claude-project-mcp-seed/server.py`
- Codex MCP는 `%USERPROFILE%\.codex\config.toml`의 `[mcp_servers.*]`에서 설정한다
- Claude project MCP는 `<repo>/.mcp.json`에 기록된다
- Gemini MCP는 운영자가 연결하기로 선택했을 때 settings JSON의 `mcpServers`로 설정한다
