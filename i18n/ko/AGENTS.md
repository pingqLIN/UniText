# AGENTS.md

## 비공개 유지 규칙

이 저장소의 내용은 사용자가 명시적으로 허용하기 전까지 비공개로 유지될 수 있습니다.

이 저장소에서 작동하는 agents는 반드시 다음 규칙을 따라야 합니다.

1. 사용자가 명시적으로 push를 요청하기 전까지는 어떤 remote에도 commit을 push하지 않습니다.
2. 사용자가 명시적으로 업로드를 요청하기 전까지는 repository 내용을 GitHub, 소셜 플랫폼, 클라우드 문서, paste site, 기타 네트워크 서비스로 업로드하지 않습니다.
3. 아래 항목은 기본적으로 특히 민감한 내용으로 간주합니다.
   - 소셜 पोस्ट 초안
   - 프로젝트 비교 메모
   - 크로스 프로젝트 협업 논의
   - 리뷰 노트
   - 전략 기획 문서
4. 사용자가 게시, push, upload, posting을 요청한 경우에도, 승인된 범위만 게시합니다.
5. 확실하지 않으면 로컬에 유지하고, 게시 전에 확인을 요청합니다.

## 적용 범위

다음 경우에도 이 규칙은 적용됩니다.

- remote가 이미 존재하는 경우
- repository가 private인 경우
- 내용이 게시 가능해 보이는 경우

private repository라고 해서 자동으로 게시 권한이 생기지는 않습니다.
