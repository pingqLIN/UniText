## Key style notes for web-app

- **ALL CAPS H1** — this is the consumer web app convention in this codebase.
- **Bold subtitle on same line** — not a blockquote; inline beneath H1.
- **GIF demos are required** — each major step gets its own animated GIF. If they don't exist yet, note `[demo GIF — add path]` as placeholder.
- **"Most importantly: It is very cute."** — optional personality closer in the Why section. Use only if the project has a mascot or distinctive character.
- **User persona table** — always present; keeps the README grounded for non-technical readers.
- **Support matrix table** — concise 2-column; no prose.
- **Minimal install section** — just 3 npm commands, no explanation needed.
- **No emoji in H2 headers** — web apps use clean headers, unlike extensions.
- **No architecture section** — web apps don't need this in the README.
