## Quick Start

1. Run `npm install`
2. Review and narrow `manifest.json`
3. Replace placeholder files in `icons/`
4. Run `npm run build`
5. Load `extension/` in `chrome://extensions`

## Project Layout

- `extension/` Chrome Load unpacked root generated by `npm run build`
- `src/background/` background service worker source
- `src/popup/` action popup UI source
- `src/options/` options page UI source
- `src/content/` content script entrypoint kept out of the manifest until host scope is known
- `src/shared/` shared storage and message helpers
- `docs/audit/` project review documents

## Security Notes

- Keep `permissions` and `host_permissions` as narrow as possible
- Do not add `"<all_urls>"` unless it is truly required and documented
- Update `docs/audit/permissions-review.md` before expanding scope
- Update `docs/audit/privacy-review.md` if any data leaves the browser
