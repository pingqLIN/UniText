## 2. Standard Social Announcement

```md
UniText has recently reached an important milestone: the project is now at the “external-review-ready + template release candidate” stage.

The core goal of UniText is to consolidate shared resources used across multiple AI CLIs into a single canonical registry, so skills, MCP definitions, agent instructions, and workflow docs do not end up scattered across different tools, formats, and versions.

What has been completed so far:
- A `registry-first, adapter-enabled, operations-governed` three-layer architecture
- Baseline coverage for all four shared resource types: `skills`, `mcp`, `agents`, and `workflow`
- A curated `8 + 4` skills review set
- A review package export flow
- A template package export + verify flow
- Cross-platform `bootstrap -> verify`
- A runnable read-only MCP baseline
- Portable `git bundle` backup support

At this point, UniText is no longer just an architectural idea. It is now an implementation baseline that is reviewable, verifiable, and packageable as a starter template.
```
